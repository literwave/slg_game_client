# 资源等级外观与主城建筑接入

## 资源地

- 林地、铁矿、石料、粮田分别新增 1—10 级独立图像，共 40 张，路径为 `assets/resources/ui/world/*_lv*.png`。
- 1—3 级通过树木数量、矿石轮廓、开采切面或田垄数量区分；4—6 级逐步增加生产棚、矿洞、储料和仓储；7—10 级增加水车、起重机、炉窑、瓦顶工坊等大型设施。
- 每格只显示一张完整资源图，无常驻等级文字、数字徽章或重复拼贴。等级同时控制占地留白，图像矩形四角仍全部收在菱形单格的 90% 范围内。
- 素材透明边缘、双线性过滤、mipmap 和中心锚点均经过 AssetDB 配置读回。源提示词、分割区域、成品校验值见 `资源等级美术来源.json`。
- 本次只调整表现，不改资源位置、地图等级、产出、服务端地图配置或资源类型 ID。

## 玩家主城

- `User.s2c_user_base_info.cityPos` 提供自己的主城坐标；`User.s2c_sync_city_pos` 迁城同步后更新位置并清除旧占地。
- `World.s2c_aoi_enter/update/leave` 的 `entityType=1` 对接玩家城池显示，其他玩家出入视野时增删；自己的主城不随 AOI 离开而消失。
- 使用现有 3×3 主城占地，渲染仅在中心格创建一次，城池占地内隐藏资源图，点击占地可选中主城。边界逐坐标校验，不绕行到相邻行。
- 玩家主城新增 1—30 级独立外观 `player_city_lv1` 至 `player_city_lv30`，由 `Build.s2c_sync_build` 的主城建筑（bid=1）等级驱动。土垣村寨逐步增加木栅、石墙、角楼、瓮城、内城与多院府邸，每一级替换实际建筑图像。
- 图宽随等级从 300 增至 474，选框、归属边界和弹窗避让使用同一外观配置。逻辑占地仍为 3×3，未知玩家建筑等级不做推断，沿用中性城池。
- 30 张图统一透明裁边、640 像素宽、线性过滤、mipmap 与底部定位锚点。逐级提示词和校验值见 `玩家主城分级美术来源.json`。
- `entityId`、拥有者和联盟 int64 ID 保留精度。旧 UI 所需的 `cityId` 是会话内本地索引，不得发给后端作为实体 ID。
- 新 World 协议未提供城池耐久和攻城目标类型，因此不显示伪造耐久、不发送旧攻城请求。

## 内城建筑

- 新协议主城的“内城 / 进入”直接打开建筑管理，沿用既有建筑预制体结构。
- 按 `BuildingDetail.Id` 与 `BuildingLv.BuildingType` 关联，读取建造和升级前置、粮木铁石成本。
- 0 级发送 `Build.c2s_create_build {bid}`，已有建筑发送 `Build.c2s_up_build {bid}`；仅 `Build.s2c_sync_build` 修改等级。
- 同一建筑请求期间按钮显示“等待确认”，避免连点；回包刷新列表、前置条件、详情及主城外观。超时恢复可操作状态，断线不重发建造请求。
- 修正 `CostStone` 漏读及石料余额写死为零的问题。资源不够或前置不满足时按钮不可用。
- 顶部资源栏只显示粮、木、铁、石（道具 1、2、3、5），数量和图标保持对应；令牌仍保留在数据层。
- 活动功能保持暂缓接入。

## 编队与分兵补充

- 原“快速分兵 / 确认分兵”仅在旧 ArmyData 存在时处理，新 World 部队无旧数据时会静默返回。现已接入 `World.c2s_edit_troop.troopInfo.posMap`，提交每名武将的目标可用兵力。
- 新部队从 User 城中可用兵力分配，输入表示本次增援；快速分兵按已上阵位置分配余数，多个位置合计不超过城中存量。伤兵保持服务器值，不参与分配。
- 保存中阻止重复提交；回包后刷新阵容并清空增援草稿。空编队、没有可用兵力、没有填写数量时均提供提示；非法数字和零分母不会形成 NaN。切换部队清空草稿，发送失败解除锁定。
- 新协议没有单独下发每将带兵上限，客户端不套用旧“武将等级 × 100”公式，也不把城中库存显示成单将容量；最终配兵规则由服务端校验。
- 离线部队协议回归 14 项、主城/Build/HUD 回归 7 项通过。TypeScript 对比无新增问题（工作区与原基线各 220 项历史诊断）。实际在线编队交互仍需服务器联调，未自动启动 Preview 或模拟输入。
