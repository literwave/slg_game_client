## 导出当前地图

地图源数据没有改时，直接在客户端项目根目录运行：

```powershell
python tools/world/export-backend-map.py
python tools/tests/backend-map-export-regression.py
```

以命令输出的 world-map-backend.zip 为交付包。只改立绘或 UI 不需要重建地图。build-campaign-map.py 会重建布局，不应作为每次同步的前置步骤。

导出器已适配新版 ResLandTypeEnum.ts，不再依赖 ResLandType.json 中已移除的 Enum 字段。导出前检查固定点、混排和四类资源 1～10 级配置；独立回归逐格核对百万格、空地、山河阻挡、城市占地、28 个地标、州域行以及包内 SHA256。

## 服务端必须同步的内容

四个 Lua 必须来自同一份包，并放到世界服**实际读取**的地图目录：

| 文件 | 用途 |
| --- | --- |
| mapRes_0.lua | 百万格资源类型、等级和可通行空地 |
| campaign-map.lua | 10 州、18 关口、10 座系统城池、占地和 regionRows |
| terrain.lua | 山河阻挡、城市保留格 |
| manifest.lua | 地图版本及各文件 SHA256 |

客户端读取 JSON，服务端读取 Lua 快照及运行中的实体状态。拉取客户端代码或仅替换图片，不会自动更新世界服。

坐标约定：cellId = y * 1000 + x，从 0 开始。Lua 使用 list[cellId][1] / [2] 读取类型和等级，不能用 #list 遍历。类型 0 要区分 emptyCells 与 blockedCells。州域使用 regionRows[y+1]，不能继续使用旧半径、扇区公式。关口以 campaign-map.lua.gates 为准，不按旧规则重新生成。
